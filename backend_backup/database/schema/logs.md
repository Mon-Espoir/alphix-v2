# Table : system_logs

## Description

Stores important system events generated by the backend, automation, and administration.

Used for debugging, auditing, maintenance, and monitoring.

---

## Fields

| Column | Type | Nullable | Key / Constraint | Description |
|---------|------|----------|------------------|-------------|
| id | BIGINT UNSIGNED | No | Primary Key, Auto Increment | Unique identifier |
| user_id | BIGINT UNSIGNED | Yes | Foreign Key → users.id (On Delete Set Null) | Related user |
| module | VARCHAR(100) | No | Index | Source module (Automation, Backend, API, Admin...) |
| action | VARCHAR(255) | No | - | Executed action |
| level | ENUM('info','warning','error','critical') | No | Default 'info' | Severity |
| message | TEXT | No | - | Detailed log message |
| context | JSON | Yes | - | Additional information |
| ip_address | VARCHAR(45) | Yes | - | User IP if available |
| created_at | TIMESTAMP | Yes | Index | Event timestamp |

---

## Relations

Belongs To → User
