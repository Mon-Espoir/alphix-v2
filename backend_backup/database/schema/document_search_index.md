# Table : document_search_index

## Description

Stores searchable text extracted from documents.

This table is automatically generated by the Python automation after OCR or PDF parsing.

It enables fast full-text search without reading the original PDF.

---

## Fields

| Column | Type | Nullable | Key / Constraint | Description |
|---------|------|----------|------------------|-------------|
| id | BIGINT UNSIGNED | No | Primary Key, Auto Increment | Unique identifier |
| document_id | BIGINT UNSIGNED | No | Foreign Key → documents.id (On Delete Cascade) | Indexed document |
| extracted_text | LONGTEXT | No | - | Complete extracted text |
| language | VARCHAR(20) | Yes | - | Detected language |
| status | ENUM('pending','processing','completed','failed') | No | Default 'pending' | Indexing status |
| created_at | TIMESTAMP | Yes | - | Creation date |
| updated_at | TIMESTAMP | Yes | - | Last update |

---

## Relations

Belongs To → Document
