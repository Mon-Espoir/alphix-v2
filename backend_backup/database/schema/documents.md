# Table : documents

## Description

Represents the central educational resource of ALPHIX.

Every academic document stored or referenced by the platform is represented here.

A document may be a course note, practical work, tutorial, examination, correction, syllabus, book, thesis, report, presentation or any future educational resource.

The physical file is stored on Google Drive while this table stores all metadata required by the platform.

This table is one of the core entities of ALPHIX.

---

---

## Managed Automatically

The automation system (Python) is responsible for:

- Detecting duplicates using SHA-256
- Calculating page count
- Reading metadata
- Uploading to Google Drive
- Retrieving Drive links
- Updating download counters
- Updating view counters
- OCR indexing
- Updating search indexes
- Updating document statistics
